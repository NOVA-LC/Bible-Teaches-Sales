# `_research/` — intermediate JW-landscape mechanics research

This directory holds in-progress research outputs from background
agents doing deep-mechanics passes on JW speakers. Files here are
**intermediate working artifacts**, not the final voice system.

When agent passes are complete, their findings synthesize into:
- `../calibration.md` — new "JW-landscape mechanics catalog" section
  with per-speaker entries and any new mechanics added to the toolbox
- `../drafting-recipe.md` — slot-menu additions if the research
  surfaces mechanics worth promoting into routine drafting use

## Status convention

Once each file lands and is reviewed:
- **Promoted** content (new mechanics, per-speaker findings worth
  keeping) moves into the parent voice/ files.
- The intermediate `_research/` file stays as the audit trail —
  do not delete after promotion. It's the receipt for *why* a
  mechanic is in the toolbox.

## Reading order

If you're looking for the operational voice system, **don't start
here**. Read in this order:
1. `../handoff-prompt.md` — the AI hand-off artifact
2. `../drafting-recipe.md` — the four-slot drafting workflow
3. `../secular-voice.md` — sales/coaching/LinkedIn translations
4. `../calibration.md` — religious commentary depth + reference

The `_research/` files are background depth, not entry points.
